MINGGU 03

HTML Lanjutan

Mempelajari penggunaan tabel, form, link, gambar, dan elemen HTML untuk membuat halaman website yang lebih terstruktur.

01. Materi yang Dipelajari

Pada minggu ketiga, saya mempelajari beberapa elemen HTML yang digunakan untuk membuat halaman website menjadi lebih lengkap dan interaktif.

  • HTML Table
  • HTML Form
  • Link atau Hyperlink
  • Menampilkan gambar
  • Input pada form
  • Button

02. Penjelasan

Tabel pada HTML digunakan untuk menampilkan data dalam bentuk baris dan kolom. Elemen seperti table, tr, th, dan td digunakan untuk membuat struktur tabel.

Selain tabel, HTML menyediakan form yang dapat digunakan untuk membuat formulir input. Form dapat berisi berbagai jenis input seperti teks, email, password, radio button, checkbox, dan button.

HTML juga memungkinkan kita menambahkan link dan gambar ke dalam halaman website. Link digunakan untuk berpindah ke halaman atau website lain, sedangkan gambar digunakan untuk menampilkan visual pada halaman.

03. Contoh HTML Table

Contoh sederhana pembuatan tabel menggunakan HTML: 

<table border="1">

    <tr>
        <th>Nama</th>
        <th>Kelas</th>
        <th>Nilai</th>
    </tr>

    <tr>
        <td>Andi</td>
        <td>TI01</td>
        <td>85</td>
    </tr>

    <tr>
        <td>Budi</td>
        <td>TI01</td>
        <td>90</td>
    </tr>

</table>

04. Contoh HTML Form

Form digunakan untuk membuat tempat pengguna memasukkan data. 

<form>

    <label>Nama:</label>

    <input type="text"
           placeholder="Masukkan nama">

    <br><br>

    <label>Email:</label>

    <input type="email"
           placeholder="Masukkan email">

    <br><br>

    <button type="submit">
        Kirim
    </button>

</form>

05. Link dan Gambar

HTML dapat digunakan untuk menambahkan hyperlink dan gambar ke dalam halaman. 

<a href="https://example.com">
    Kunjungi Website
</a>

<br><br>

<img src="gambar.jpg"
     alt="Contoh Gambar"
     width="300">

06. Hasil Pembelajaran

Setelah mempelajari materi minggu ketiga, saya dapat menggunakan berbagai elemen HTML untuk membuat halaman website yang lebih lengkap dan terstruktur.

✓ Yang Saya Pahami

Saya dapat membuat tabel sederhana, membuat form input, menambahkan link, serta menampilkan gambar menggunakan HTML.

07. Kesimpulan

HTML tidak hanya digunakan untuk membuat teks dan judul, tetapi juga dapat digunakan untuk menyusun data menggunakan tabel, membuat formulir, menambahkan gambar, dan membuat navigasi melalui hyperlink. Dengan memahami elemen-elemen tersebut, halaman website dapat dibuat lebih informatif dan terstruktur.
