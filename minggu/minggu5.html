MINGGU 05

CSS Layout & Responsive Design

Mempelajari teknik mengatur tata letak halaman website dan membuat tampilan yang dapat menyesuaikan berbagai ukuran layar.

01. Materi yang Dipelajari

Pada minggu kelima, saya mempelajari bagaimana mengatur tata letak elemen pada halaman website menggunakan CSS. Selain itu, saya juga mempelajari konsep responsive design.

  • CSS Box Model
  • Margin
  • Padding
  • Border
  • Width dan Height
  • CSS Flexbox
  • CSS Grid
  • Responsive Design
  • Media Query

02. Penjelasan

CSS Layout digunakan untuk mengatur posisi dan susunan elemen pada halaman website. Dengan layout yang baik, informasi dapat ditampilkan secara teratur dan mudah dibaca.

Salah satu konsep dasar dalam layout CSS adalah Box Model. Setiap elemen HTML dapat dianggap sebagai sebuah kotak yang memiliki content, padding, border, dan margin.

Selain Box Model, CSS menyediakan Flexbox dan Grid untuk membantu membuat layout yang lebih fleksibel.

Responsive Design digunakan agar tampilan website dapat menyesuaikan ukuran layar, baik desktop, tablet, maupun smartphone.

03. CSS Box Model

CSS Box Model terdiri dari beberapa bagian, yaitu content, padding, border, dan margin. 

.box {

    width: 300px;

    padding: 20px;

    border: 2px solid black;

    margin: 20px;

}

Pada contoh tersebut, width digunakan untuk menentukan lebar content, padding memberikan jarak antara content dan border, sedangkan margin memberikan jarak dengan elemen lainnya.

04. CSS Flexbox

Flexbox digunakan untuk mengatur elemen dalam satu dimensi, baik secara horizontal maupun vertikal. 

.container {

    display: flex;

    justify-content: center;

    align-items: center;

    gap: 20px;

}

Property display: flex digunakan untuk mengaktifkan Flexbox. Sedangkan justify-content dan align-items digunakan untuk mengatur posisi elemen.

05. CSS Grid

CSS Grid digunakan untuk membuat layout berbentuk baris dan kolom sehingga cocok digunakan untuk membuat card atau struktur halaman website. 

.grid {

    display: grid;

    grid-template-columns:
        repeat(3, 1fr);

    gap: 20px;

}

06. Responsive Design

Responsive Design merupakan teknik membuat website agar dapat menyesuaikan tampilan berdasarkan ukuran layar perangkat yang digunakan.

Salah satu cara membuat website responsive adalah menggunakan Media Query. 

@media (max-width: 600px) {

    .container {

        width: 90%;

    }

    .grid {

        grid-template-columns: 1fr;

    }

}

Ketika lebar layar kurang dari atau sama dengan 600px, layout dapat diubah menjadi satu kolom sehingga lebih nyaman digunakan pada smartphone.

07. Hasil Pembelajaran

Setelah mempelajari CSS Layout dan Responsive Design, saya dapat mengatur posisi berbagai elemen pada halaman website dan membuat tampilan yang menyesuaikan ukuran layar.

✓ Yang Saya Pahami

Saya memahami penggunaan Box Model, Flexbox, Grid, dan Media Query untuk membuat layout website yang rapi dan responsive.

08. Kesimpulan

CSS Layout sangat penting dalam pengembangan website karena membantu mengatur posisi dan susunan elemen. Dengan menggunakan Flexbox, Grid, dan Media Query, website dapat memiliki tampilan yang terstruktur dan responsive pada berbagai perangkat.
