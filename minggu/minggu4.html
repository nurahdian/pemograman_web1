MINGGU 04

Dasar-Dasar CSS

Mempelajari CSS untuk mengatur tampilan, warna, ukuran, dan tata letak halaman website.

01. Materi yang Dipelajari

Pada minggu keempat, saya mempelajari CSS atau Cascading Style Sheets yang digunakan untuk mengatur tampilan halaman website.

  • Pengertian CSS
  • Fungsi CSS
  • CSS Inline
  • CSS Internal
  • CSS External
  • Selector CSS
  • Property dan Value

02. Penjelasan

CSS atau Cascading Style Sheets merupakan bahasa yang digunakan untuk mengatur tampilan dan desain halaman website. Dengan CSS, halaman HTML yang sebelumnya hanya memiliki struktur dapat dibuat menjadi lebih menarik dan mudah digunakan.

CSS dapat digunakan untuk mengatur berbagai hal seperti warna teks, ukuran huruf, background, jarak antar elemen, border, posisi elemen, hingga tata letak halaman.

Berdasarkan cara penggunaannya, CSS dapat ditulis menggunakan tiga cara, yaitu Inline CSS, Internal CSS, dan External CSS.

03. Jenis-Jenis CSS

Inline CSS

CSS ditulis langsung pada elemen HTML menggunakan atribut style. 

<p style="color: blue;">
    Belajar CSS
</p>

Internal CSS

CSS ditulis di dalam tag <style> pada bagian head HTML. 

<style>

    p {
        color: blue;
        font-size: 18px;
    }

</style>

External CSS

CSS dibuat dalam file terpisah kemudian dihubungkan dengan halaman HTML. 

<link rel="stylesheet"
      href="style.css">

04. CSS Selector

Selector digunakan untuk menentukan elemen HTML yang akan diberikan style. Beberapa selector dasar yang dipelajari antara lain selector elemen, class, dan id. 

/* Selector elemen */

p {
    color: black;
}


/* Selector class */

.judul {
    font-size: 30px;
}


/* Selector id */

#header {
    background: blue;
}

05. Property dan Value

Dalam CSS, property digunakan untuk menentukan bagian tampilan yang ingin diubah, sedangkan value menentukan nilai dari property tersebut. 

h1 {
    color: blue;
    font-size: 32px;
    text-align: center;
}

Pada contoh tersebut, color digunakan untuk mengatur warna teks, font-size untuk ukuran huruf, dan text-align untuk mengatur posisi teks.

06. Hasil Pembelajaran

Setelah mempelajari CSS, saya dapat mengubah tampilan halaman HTML dengan memberikan warna, ukuran, jarak, dan pengaturan teks menggunakan CSS.

✓ Yang Saya Pahami

Saya memahami fungsi CSS dan dapat menggunakan Inline, Internal, maupun External CSS untuk mengatur tampilan halaman website.

07. Kesimpulan

CSS merupakan bagian penting dalam pengembangan website karena digunakan untuk mengatur tampilan halaman. Dengan menggunakan CSS, website dapat memiliki tampilan yang lebih menarik, teratur, dan nyaman untuk digunakan.
