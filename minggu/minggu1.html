MINGGU 01

Pengenalan Pemrograman Web

Memahami konsep dasar website dan teknologi yang digunakan dalam pengembangan web.

01. Materi yang Dipelajari

Pada minggu pertama, saya mempelajari konsep dasar pemrograman web serta bagaimana sebuah website dapat dibuat dan ditampilkan melalui browser.

  • Pengertian website
  • Website statis dan dinamis
  • Client dan server
  • Pengenalan HTML
  • Struktur dasar dokumen HTML

02. Penjelasan

Website merupakan kumpulan halaman yang dapat diakses melalui internet menggunakan browser. Dalam pengembangan website terdapat beberapa teknologi yang digunakan, seperti HTML untuk membuat struktur, CSS untuk mengatur tampilan, dan JavaScript untuk memberikan interaksi.

Pada tahap awal pembelajaran, HTML menjadi dasar yang penting karena HTML digunakan untuk menentukan struktur dan isi dari sebuah halaman website.

03. Contoh Kode

Berikut contoh struktur dasar HTML yang dipelajari: 

<!DOCTYPE html>
<html>

<head>
    <title>Website Saya</title>
</head>

<body>

    <h1>Hello World</h1>

    <p>
        Ini adalah website pertama saya.
    </p>

</body>

</html>

04. Hasil Pembelajaran

Setelah mempelajari materi minggu pertama, saya memahami konsep dasar pemrograman web dan mengetahui fungsi HTML dalam membuat struktur sebuah halaman website.

✓ Yang Saya Pahami

Saya dapat membuat struktur dasar halaman HTML menggunakan elemen seperti html, head, title, body, h1, dan p.

05. Kesimpulan

Pembelajaran pada minggu pertama menjadi dasar untuk memahami pengembangan website. HTML merupakan salah satu teknologi utama yang digunakan untuk membangun struktur halaman web sebelum dikembangkan menggunakan CSS dan JavaScript.
