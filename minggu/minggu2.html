MINGGU 02

Dasar-Dasar HTML

Mempelajari struktur, elemen, tag, dan atribut HTML untuk membuat halaman web.

01. Materi yang Dipelajari

Pada minggu kedua, saya mempelajari dasar-dasar HTML sebagai bahasa markup yang digunakan untuk membuat struktur halaman website.

  • Pengertian HTML
  • Struktur dasar HTML
  • Tag HTML
  • Elemen HTML
  • Atribut HTML
  • Heading dan paragraph
  • Link dan gambar

02. Penjelasan

HTML atau HyperText Markup Language merupakan bahasa markup yang digunakan untuk membuat struktur sebuah halaman web.

HTML menggunakan berbagai tag untuk menentukan bagian-bagian halaman, seperti judul, paragraf, gambar, link, dan berbagai elemen lainnya.

Setiap elemen HTML biasanya memiliki tag pembuka dan tag penutup. Beberapa elemen juga dapat memiliki atribut yang memberikan informasi tambahan.

03. Contoh Kode

Berikut contoh penggunaan beberapa elemen HTML: 

<!DOCTYPE html>
<html>

<head>
    <title>Belajar HTML</title>
</head>

<body>

    <h1>Belajar Pemrograman Web</h1>

    <p>
        Saya sedang belajar HTML.
    </p>

    <a href="https://example.com">
        Kunjungi Website
    </a>

</body>

</html>

04. Hasil Pembelajaran

Setelah mempelajari HTML dasar, saya dapat memahami fungsi tag dan elemen HTML serta membuat struktur halaman website sederhana.

✓ Yang Saya Pahami

Saya dapat menggunakan heading, paragraf, link, dan beberapa elemen HTML lainnya untuk membuat halaman web.

05. Kesimpulan

HTML merupakan dasar penting dalam pengembangan website karena digunakan untuk membentuk struktur dan menyusun konten pada halaman web. Pemahaman HTML menjadi dasar sebelum mempelajari CSS dan JavaScript.
