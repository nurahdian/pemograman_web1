MINGGU 06

Dasar-Dasar JavaScript

Mempelajari JavaScript sebagai bahasa pemrograman untuk memberikan interaksi pada halaman website.

01. Materi yang Dipelajari

Pada minggu keenam, saya mempelajari dasar-dasar JavaScript dan bagaimana JavaScript dapat digunakan untuk memberikan interaksi pada website.

  • Pengertian JavaScript
  • Fungsi JavaScript
  • Variabel
  • Tipe data
  • Operator
  • Function
  • Event
  • DOM sederhana

02. Penjelasan

JavaScript merupakan bahasa pemrograman yang digunakan untuk membuat halaman website menjadi lebih interaktif. JavaScript dapat digunakan untuk merespons tindakan yang dilakukan pengguna pada halaman web.

Jika HTML digunakan untuk membuat struktur dan CSS digunakan untuk mengatur tampilan, JavaScript dapat digunakan untuk menambahkan logika dan interaksi.

JavaScript dapat dijalankan langsung pada browser sehingga pengguna dapat berinteraksi dengan halaman website tanpa harus melakukan proses pada server.

03. Variabel dan Tipe Data

Variabel digunakan untuk menyimpan nilai yang dapat digunakan kembali dalam program. 

let nama = "Andi";

let umur = 20;

let mahasiswa = true;

console.log(nama);

console.log(umur);

console.log(mahasiswa);

JavaScript memiliki beberapa tipe data seperti String, Number, Boolean, Array, dan Object.

04. Function

Function merupakan sekumpulan instruksi yang dibuat untuk menjalankan tugas tertentu. Function dapat dipanggil kembali ketika dibutuhkan. 

function salam() {

    console.log("Halo, selamat belajar!");

}

salam();

Dengan function, kode program dapat dibuat lebih terstruktur dan dapat digunakan kembali.

05. Event dan Interaksi

Event digunakan untuk menjalankan suatu perintah ketika terjadi tindakan tertentu dari pengguna, misalnya ketika tombol diklik. 

<button onclick="tampilkanPesan()">

    Klik Saya

</button>


<script>

function tampilkanPesan() {

    alert("Halo! Selamat datang.");

}

</script>

06. Pengenalan DOM

DOM atau Document Object Model memungkinkan JavaScript mengakses dan mengubah elemen HTML pada halaman. 

<h2 id="judul">
    Teks Awal
</h2>


<script>

document.getElementById("judul")
        .innerHTML = "Teks Baru";

</script>

Pada contoh tersebut, JavaScript mencari elemen dengan id "judul" kemudian mengubah isi teksnya.

07. Hasil Pembelajaran

Setelah mempelajari JavaScript, saya dapat memahami dasar bahasa pemrograman JavaScript dan mengetahui bagaimana JavaScript digunakan untuk memberikan interaksi pada website.

✓ Yang Saya Pahami

Saya memahami penggunaan variabel, tipe data, function, event, dan DOM sederhana dalam JavaScript.

08. Kesimpulan

JavaScript melengkapi HTML dan CSS dalam pengembangan website dengan memberikan kemampuan interaksi dan logika program. Dengan memahami dasar JavaScript, website dapat dibuat lebih dinamis dan interaktif bagi pengguna.
