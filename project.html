PROSES PENGERJAAN

Tahapan Pembuatan Project

Project dibuat melalui beberapa tahap mulai dari perencanaan struktur hingga pengembangan tampilan dan interaksi.

01

Perencanaan

Menentukan tujuan website, struktur halaman, konten, dan kebutuhan navigasi.

02

Struktur HTML

Membuat struktur dasar halaman menggunakan HTML dan menyusun konten website.

03

Styling CSS

Mengatur warna, ukuran, layout, jarak, dan tampilan website menggunakan CSS.

04

JavaScript

Menambahkan fungsi interaksi sederhana menggunakan JavaScript.

05

Responsive

Menyesuaikan tampilan website agar dapat digunakan pada berbagai ukuran layar.

06

Evaluasi

Memeriksa kembali tampilan, navigasi, dan fungsi website sebelum project diselesaikan.

HASIL PROJECT

Menerapkan Materi yang Telah Dipelajari

Melalui project ini, saya dapat menggabungkan materi HTML, CSS, dan JavaScript menjadi sebuah website yang memiliki struktur jelas, tampilan rapi, dan responsive.
