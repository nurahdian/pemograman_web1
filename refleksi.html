PEMROGRAMAN WEB I

Refleksi Pembelajaran

Catatan mengenai pengalaman, perkembangan, dan pemahaman saya selama mengikuti perkuliahan Pemrograman Web I.

PENGALAMAN BELAJAR

Dari Mengenal Web Hingga Membuat Website

Selama mengikuti mata kuliah Pemrograman Web I, saya mempelajari berbagai dasar yang diperlukan untuk membangun sebuah website. Pembelajaran dimulai dari HTML, kemudian dilanjutkan dengan CSS dan JavaScript.

Setiap materi memberikan pemahaman baru mengenai bagaimana sebuah website dirancang, dibuat, dan dikembangkan agar dapat digunakan dengan baik.

PERKEMBANGAN

Perkembangan yang Saya Rasakan

01

HTML

Saya mulai memahami cara membuat struktur halaman menggunakan berbagai elemen HTML.

02

CSS

Saya dapat mengatur tampilan, warna, ukuran, dan layout halaman menggunakan CSS.

03

JavaScript

Saya mulai memahami bagaimana JavaScript digunakan untuk memberikan interaksi pada website.

TANTANGAN

Kesulitan yang Dihadapi

Salah satu kesulitan yang saya alami adalah memahami hubungan antara HTML, CSS, dan JavaScript. Setiap teknologi memiliki fungsi yang berbeda tetapi harus digunakan secara bersamaan untuk menghasilkan website yang baik.

Selain itu, saya juga perlu mencoba berbagai kode secara langsung agar dapat memahami bagaimana perubahan kode memengaruhi tampilan website.

SOLUSI

Cara Mengatasinya

Untuk mengatasi kesulitan tersebut, saya mencoba memahami materi secara bertahap dan langsung mempraktikkannya melalui contoh sederhana.

Dengan melakukan praktik dan mencoba memperbaiki kesalahan kode, saya menjadi lebih memahami cara kerja HTML, CSS, dan JavaScript.

PEMBELAJARAN TERPENTING

Tidak Hanya Tentang Menulis Kode

Hal penting yang saya dapatkan dari perkuliahan ini adalah bahwa membuat website bukan hanya tentang menulis kode. Struktur informasi, tampilan, navigasi, dan kenyamanan pengguna juga perlu diperhatikan.

Saya juga belajar bahwa kesalahan dalam kode merupakan bagian dari proses pembelajaran. Dengan mencoba, menemukan kesalahan, dan memperbaikinya, pemahaman terhadap materi menjadi lebih baik.
